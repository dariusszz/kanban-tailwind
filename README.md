# kanban-tailwind

Kanban interface built with React, Vite, Tailwind CSS, and JSON Server.

## Run locally

```bash
npm install
npm start
```

- Vite frontend: http://localhost:5173
- JSON Server API: http://localhost:3001/tasks

Task data is stored in `src/data/tasks.json`. The app supports creating, editing, deleting (with confirmation), searching tasks after three characters, filtering by priority, and adding tasks directly to any status column.
